# Карта камер фотовидеофиксации (Кузбасс)

Интерактивная карта по Excel-реестру стационарных, передвижных и мобильных комплексов.

- `index.html` — карта: Leaflet, 4 подложки (OSM, CARTO dark, OpenTopoMap, Esri imagery), кластеризация,
  фильтры по виду нарушения, поиск по адресу, маршруты мобильных комплексов, геолокация.
  На десктопе панель слева, на телефоне — нижний лист.
- `data.js` — данные, сгенерированные из Excel.
- `convert.py` — конвертер Excel → `data.js`.
- `PRODUCT.md`, `.impeccable/` — продуктовый и дизайн-контекст (коммитить).

## Обновление данных

```sh
uv run --with openpyxl python -I convert.py /путь/к/файлу.xlsx
```

Конвертер пишет в stderr строки, которые не удалось разобрать или классифицировать.

## Запуск

Открыть `index.html` в браузере (нужен интернет для тайлов и библиотек) или
`python3 -m http.server` в этой папке. Выбор подложки и фильтры сохраняются в localStorage.
